# Remotion Skills — Master Index

This is a flat index of every component across the 22 Remotion skills. Useful for picking the right component for a job without having to read each SKILL.md.

For full details (anti-patterns, recipes, audio cues, pairings) read the per-skill SKILL.md.

## How to read

- **Default canvas**: V = vertical 1080×1920 (TikTok/Reels), L = landscape 1920×1080, A = either
- **Loops?**: Y = safe to hold 5+ second Sequence, N = one-shot
- "BG" tags mean the component is best used behind/under other content; "OL" means it overlays footage.

## Things to NEVER do (cross-skill anti-patterns)

- **Don't stack 3+ CTAs simultaneously** — stacks > 2 read as desperate.
- **Don't chain >2 reactions back-to-back** — meme-stack overload.
- **Don't layer GlitchText + NeonGlow simultaneously** — effects cancel each other.
- **Don't put two competing background skills behind content** (e.g. ParticleField + WavyLines) without opacity/mixBlendMode.
- **Don't chain three tech components in a row** (CodeSnippet → TerminalCommand → FileTree) without a B-roll break — dense info dump.
- **Don't render any of these without `--mute`** if the composition has no `<Audio>` — `--audio-codec=no-audio` is INVALID and will error.
- **Don't stack BrandReveal + ChapterBumper at the start** — both are "title moment" devices.
- **Don't use ExpectedVsHappened, HundredSlam, CryingLaugh, or CensorBar in serious editorial content** — all meme-coded.

## Render flag cheat sheet (all skills agree)

```bash
# Standard render (silent video, h264)
npx remotion render src/index.ts <CompositionId> /tmp/out.mp4 --mute --codec h264

# Transparent overlay (ProRes 4444 with alpha for compositing in Premiere)
npx remotion render src/index.ts <CompositionId> /tmp/out.mov --mute --codec prores --prores-profile 4444

# To strip the silent audio track post-process (rare — Premiere accepts silent AAC)
ffmpeg -i in.mp4 -c:v copy -an out.mp4
```

**NEVER use `--audio-codec=no-audio`** — invalid flag. Valid `--audio-codec` values are `pcm-16 | aac | mp3 | opus`. Use `--mute` to silence.
