Install guide

Four steps. You're in.

Get the Claude panel running inside Premiere Pro. No API key needed.

Step 1

Download the extension

Grab the files and unzip them anywhere on your computer.

Download .zip
or, if you use git
Terminal
git clone https://github.com/iprincemax72-maker/claude-extension-premiere-pro-2026.git
Step 2

Run the one-step installer

Open the unzipped folder in a terminal and run one command. It sets up everything (Node, the Claude CLI, ffmpeg) and adds the panel to Premiere. Takes about 3 minutes.

Terminal — macOS
bash install.sh
PowerShell — Windows
powershell -ExecutionPolicy Bypass -File install.ps1

Close Premiere Pro first so it picks up the new panel when you reopen it.

Step 3

Connect your Claude

Log in once. The panel runs on your own Claude plan — there's no API key to paste anywhere.

Terminal
claude /login

A browser tab opens — click Allow. That's it. (Skip this if you're already logged into Claude Code.)

Step 4

Open it in Premiere

Launch Premiere Pro and open the panel:

  • In the menu bar: Window → Extensions → Claude
  • The status dot turns green within a second or two.
  • Type what you want — e.g. a 3-second logo intro that says HELLO — and hit ↵.

You're done. First render takes about a minute. Drop it on your timeline and keep editing. 🎬
