Install guide

Up and running in
one command.

The installer handles Node, the Claude CLI, ffmpeg, and the Remotion project for you. Close Premiere first so it picks up the panel on next launch.

Premiere Pro 2024+ A Claude Pro or Max plan macOS or Windows 10/11 No API key
STEP 01

Run the installer

Pick your OS, copy the block, and paste it into a terminal.

Terminal — macOS
# clone, then run the installer
git clone https://github.com/iprincemax72-maker/claude-extension-premiere-pro-2026.git
cd claude-extension-premiere-pro-2026
bash install.sh
PowerShell — Windows
# clone, then run the installer
git clone https://github.com/iprincemax72-maker/claude-extension-premiere-pro-2026.git
cd claude-extension-premiere-pro-2026
powershell -ExecutionPolicy Bypass -File install.ps1

What it does — safe to re-run anytime for updates:

  1. Installs Node.js, the Claude Code CLI, and ffmpeg if they're missing
  2. Enables PlayerDebugMode so Premiere loads the panel (no admin needed)
  3. Copies the panel into Adobe's CEP extensions folder
  4. Drops the local bridge into ~/PremiereClaude/
  5. Pre-scaffolds the Remotion project and runs npm install once — the slow step (2–4 min), so your first render is ~60s, not ~5 min
  6. Places a desktop launcher for the bridge
STEP 02

Log in to Claude

If the installer says the Claude CLI isn't logged in, open a new terminal and run:

Terminal
claude /login

A browser tab opens — click Allow. It runs on your existing Claude subscription, so there's no API key to paste anywhere.

STEP 03

First run

  1. Start the bridge — double-click Claude Bridge.command (macOS) or Claude Bridge.bat (Windows) on your Desktop. A terminal opens, running on localhost:3737.
  2. Open the panel — in Premiere: Window → Extensions → Claude. The status pill turns green.
  3. Describe a graphic — type a prompt or tap a suggestion chip and hit ↵. Claude writes the code and renders it.
  4. Place it — the render card shows Import to Timeline / Preview / Changes. Nothing is auto-imported — you decide.
  5. When you're done — close the bridge terminal window to stop the server.
STEP 04

If something's off

"Bridge offline" in the panel
Start the bridge — double-click Claude Bridge.command / .bat on your Desktop.
Panel doesn't show in Premiere
Quit and reopen Premiere completely. Still missing? Re-run the installer.
claude not found after install
The npm global bin isn't on your PATH yet. Open a fresh terminal and re-run the installer.
First render takes 5+ minutes
The Remotion npm install didn't finish. Run it in ~/PremiereClaude/remotion-intro.
"ffmpeg not found"
brew install ffmpeg (macOS) or winget install -e --id Gyan.FFmpeg (Windows).
Cmd+V won't paste in the panel
Premiere captures it. Use Shift+V for text, Shift+B for an image.

That's it — back to editing.
