Get started

Install it in four steps.

1
2
3
4
Step 1

Download the extension

It runs on your account, sign in, then grab it for your computer.

Download for macOS Download for Windows
Sign in to download

Creating an account is free. The download unlocks once you're signed in, and you sign in inside the panel too, to render.

Same panel, cross-platform, Windows is a one-click .exe installer; macOS is a zip.

Step 2

Run the one-step installer

It sets up everything (Node, the Claude CLI, ffmpeg, Remotion) and adds the panel to Premiere. ~3 minutes.

Terminal, macOS
bash install.sh

Just double-click ClaudeForPremiere-Setup.exe and follow the wizard. No terminal, no commands.
It's not code-signed yet, so if you see a blue "Windows protected your PC" screen, click More info → Run anyway.

Prefer the zip / a command?
Grab claude-premiere-pro-windows.zip from the releases page, extract it, then double-click INSTALL.bat, or run powershell -ExecutionPolicy Bypass -File install.ps1.

Close Premiere Pro first so it picks up the panel when you reopen it.

Step 3

Connect your Claude

Log in once. It runs on your own Claude plan, so there's no API key to paste.

Terminal
claude /login

A browser tab opens, click Allow. (Skip if you're already logged into Claude Code.)

Step 4

Open it in Premiere

Launch Premiere Pro and open the panel:

  • Window → Extensions → Flimify
  • The status dot turns green in a second or two.
  • Type something like a 3-second logo intro that says HELLO and hit ↵.

You're done. First render takes about a minute, then it's on your timeline. 🎬
